# 《破绽》玩家须知

> 打印这一页放在桌上，或者开局前念一遍。

**你们是侦探。** 对面的嫌疑人在撒谎，你们要用桌上的线索卡戳穿他的每一条证词。

## 开局

- 对设备说「**开始审讯**」。
- 设备会依次讲：案情、嫌疑人的三条证词、规则。
- 桌上摊开所有线索卡。**有的卡帮不上忙。**

## 审问

- 想问什么就问什么：「你九点在哪？」「你最近缺钱吗？」
- 嫌疑人会狡辩、打太极，还会说漏嘴。仔细听，失言里藏着线索。
- 你们可以先商量好再开口，设备只回答说给它听的话。

## 出示线索卡

拍出一张卡，大声说：

> 「用 **二号卡** 反驳 **证词一**！」

也可以直接说卡上的内容：「电梯监控拍到你九点半上了十八楼！」

| 结果 | 会发生什么 |
|---|---|
| 戳中了 | 嫌疑人被迫让步，语气也会变：镇定 → 狡辩 → 慌乱 → 崩溃 |
| 没戳中 | 律师离现场又近了一步 |

## 输赢

- **赢**：三条证词全部戳穿，嫌疑人崩溃认罪。
- **输**：出示错 **3 次**，或者审讯超过 **15 分钟**，律师到场，嫌疑人不再开口。

不管输赢，结束后设备都会揭晓真相。

## 随时可以说

| 想做什么 | 就说 |
|---|---|
| 再听一遍证词 | 「念一下证词」 |
| 再听一张卡 | 「念一下三号卡」 |
| 看还剩多少机会 | 「还有几次机会」 |
| 没听清 | 「再说一遍」 |
| 再来一局 | 「重新开始」 |
| 不玩了 | 「结束游戏」 |
