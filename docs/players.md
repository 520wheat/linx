# 《破绽》玩家须知

> 打印这一页放在桌上，或者开局前念一遍。

**你们是侦探。** 对面的嫌疑人在撒谎，你们要用桌上的线索卡戳穿他的每一条证词。

## 开局

- 对设备说「**开始审讯**」。
- 设备会依次讲：案情、嫌疑人的开场证词、一句话玩法。想听完整规则就说「**规则**」。
- 桌上摊开所有线索卡。**有的卡帮不上忙。**

## 审问

- 想问什么就问什么：「你九点在哪？」「你最近缺钱吗？」
- 嫌疑人会狡辩、打太极，还会说漏嘴。仔细听，失言里藏着线索。
- **证词会越审越多。** 问到关键的事，他会说出一条新证词；被戳破后，他会改口编出新的谎话。旁白会告诉你这是「证词几」。
- 手里的卡对不上任何一条证词？想想这张卡和什么事有关，围着它追问。实在问不出来也别急：他说出口的都被戳破以后，再多问两句，他会自己说漏。
- 你们可以先商量好再开口，设备只回答说给它听的话。

## 出示线索卡

拍出一张卡，大声说：

> 「用 **二号卡** 反驳 **证词一**！」

也可以拿着卡直接说：「看这张，电梯监控拍到你九点半上了十八楼！」

| 结果 | 会发生什么 |
|---|---|
| 戳中了 | 嫌疑人被迫让步，语气也会变：镇定 → 狡辩 → 慌乱 → 崩溃 |
| 沾边但不够硬 | 旁白提示「还不够硬」，**不扣次数** |
| 没戳中 | 律师离现场又近了一步 |

只是在提问里提到卡的内容（「没人点歌，那半小时你在干嘛？」），驳不倒也不扣次数。

## 输赢

- **赢**：戳穿他的全部谎话，嫌疑人崩溃认罪。破案后按失误评级：零失误 S，出示错误、要提示、靠他自己说漏都算失误。
- **输**：出示错 **3 次**，或者审讯超过 **15 分钟**，律师到场，嫌疑人不再开口。

结束后说「**讲讲真相**」听完整经过。输了不会自动揭晓，可以先说「重新开始」再试一次。

第一次玩？「开始审讯」会先进入三分钟的新手教学关《消失的布丁》，打完说「下一个案子」进入正式案件。

## 随时可以说

| 想做什么 | 就说 |
|---|---|
| 再听一遍证词 | 「念一下证词」 |
| 再听一张卡 | 「念一下三号卡」 |
| 看还剩多少机会 | 「还有几次机会」 |
| 没听清 | 「再说一遍」 |
| 听完整规则 | 「规则」 |
| 卡住了 | 「给点提示」（同一处再说一次，提示更具体；会影响评级） |
| 听答案 | 「讲讲真相」（对局结束后） |
| 再来一局 | 「重新开始」 |
| 换一个案子 | 「下一个案子」；网页开玩可点「选关」 |
| 不玩了 | 「结束游戏」 |
