# 午夜便利店

七牛云黑客松作品。用灵矽做语音审讯：玩家和嫌疑人坐在审讯室里，靠线索卡拆穿他的不在场证明。当前仓库是可玩 Demo，只做这一案。

## 玩法

你是审讯员，对面是嫌疑人陈默。他会撒谎、圆谎、慌、漏嘴。桌上的线索卡是已经确认的事实，可以随时点开看。

一轮只有三步：

1. 看线索卡。
2. 点亮最多两张，表示正在出示这两条证据。
3. 按住「问话」开口质问。松手后，嫌疑人必须接这两条事实。

单张卡通常压不住他。要把两件对得上的事实叠在一起再问，像柯南里「真相只有一个」。问到冲突时，屏幕会亮一句短提示，提示只帮你对准，不替你破案。

本案的唯一组合是「便利店小票」和「小区监控」：小票写 21:03 结账，监控却在 21:02 拍到他还在小区门口。第一次压中，他会慌、开始漏嘴；再追问一次，不在场证明垮掉，审讯结束。

限时 8 分钟。点错卡也能问，只是他更容易圆过去。

## 这一案

21:10，便利店店员被发现倒在柜台后。陈默声称 21:00 一直在店里买烟。

- 便利店小票：21:03 结账，只买了一包烟。
- 小区监控：21:02 单元门口拍到陈默。
- 通话记录：20:58 打给同事，时长 41 秒。
- 本人陈述：自称九点整一直待在店里。

## 本地打开

Chrome 或 Edge 里允许麦克风。

```bash
python -m http.server 8080
```

浏览器打开 http://localhost:8080

没有 Python 时，也可以直接打开 `index.html`。部分浏览器在本地文件地址下会关掉语音识别，这时仍可按住问话，用出示的卡片推进对话。

## 语音

Demo 先用浏览器语音：听玩家说话，并用中文语音念嫌疑人的回答。灵矽实时通道留在 `js/linx.js`。有 Token、Device-Id 后，把 `js/voice.js` 的听和说换成 `wss://xrobo-io.qiniuapi.com/v1/ws/` 即可，玩法不用改。
